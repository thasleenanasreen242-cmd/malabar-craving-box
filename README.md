# Malabar Craving Box

A premium homemade Malabar snack-box ordering experience.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Vercel deployment
- Supabase, Razorpay and WhatsApp Cloud API integrations (configured through environment variables)

## Development

Install dependencies with `npm install`, then run `npm run dev`.

See `.env.example` for the integrations required to enable live ordering, payments and WhatsApp automation.
